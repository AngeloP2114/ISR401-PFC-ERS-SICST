# CHANGELOG

Todos los cambios relevantes realizados sobre el ERS/SRS del
Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)
se documentan en este archivo.

## [2A-CCB-v4] - 2026-08-09

### Añadido

- RFC-01: se incorporó el requisito funcional RF-33 para gestionar el estado y escalamiento de las alertas terapéuticas.
- RFC-02: se incorporó el requisito no funcional RNF-13 para establecer un tiempo verificable de respuesta de las alertas.
- RFC-03: se incorporó la restricción RES-15 relacionada con la revocatoria del consentimiento y el bloqueo de nuevas capturas o accesos asociados.

### Cambiado

- Se actualizaron los requisitos y artefactos afectados por las decisiones aprobadas por el Comité de Control de Cambios.
- Se actualizaron las relaciones de trazabilidad relacionadas con RF-33, RNF-13 y RES-15.
- El ERS/SRS pasó de la versión 2A-Fagan-v3 a la versión 2A-CCB-v4.

### Eliminado

- No se eliminaron requisitos como resultado de las solicitudes de cambio aprobadas.

---

## [2A-Fagan-v3] - 2026-08-09

### Cambiado

- Se corrigieron los 16 defectos aceptados durante la inspección Fagan.
- Se resolvieron 12 defectos de severidad Mayor y 4 de severidad Menor.
- Se actualizaron requisitos funcionales, requisitos no funcionales, prioridades, criterios de verificación y relaciones de trazabilidad.

### Eliminado

- Se eliminaron referencias inconsistentes a fuentes de evidencia que no estaban definidas formalmente en el ERS.

---

## [2A-Final-v2] - 2026-08-02

### Estado

- Versión del ERS/SRS utilizada como base para la inspección formal Fagan de la PE4.
